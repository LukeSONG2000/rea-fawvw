# 车控功能待选清单

> 最新逐车实证见 [CAPABILITY-EXPLORATION-2026-11-17.md](CAPABILITY-EXPLORATION-2026-11-17.md)，本页为早期入口整理。

基于当前已登录高尔夫 A8 GTI 的原生车控页，记录时间为 2026-11-16。下面记录实际可见入口，车辆指令尚未执行验证。

| 功能 | 页面用途 | 当前验证 |
|---|---|---|
| 启动引擎 | 发动机启动操作入口 | 入口可见 |
| 开锁 | 车辆解锁入口 | 入口可见 |
| 上锁 | 车辆锁车入口 | 入口可见 |
| 车辆状态 | 查看车辆状态详情 | 入口可见 |
| 闪灯 | 灯光寻车入口 | 入口可见 |

| 在线寻车 | 车辆位置查询入口 | 入口可见 |
| 车窗 | 车窗相关功能，子选项待核对 | 入口可见 |
| 车联权益 | 车联网服务与权益入口 | 入口可见 |
| 自定义 | 车控快捷功能配置入口 | 入口可见 |

页面还显示车型、续航、油量/能源、点火和门锁状态。顶部有车辆选择及图标入口，图标的具体用途尚待逐项核对。原账号内其他车型可能具有不同入口，应按选中车辆能力动态呈现。

用户明确要求去掉开屏广告，并从上述清单选取最小功能。用户要求先整理建议，当前保留原车控页可见入口。登录方式优先级为账号密码、验证码、运营商一键授权、微信、苹果。账号密码登录已由用户确认成功。

## 用户确认的边界

本轮只整理功能和分类建议，暂不按建议裁剪车控按钮。产品范围限定为车辆控制及相关信息查询，排除营销与冗余内容。开屏广告、首次安装介绍与协议展示是已单独授权修改的项目。

## 建议分类

| 分类 | 内容 | 建议 |
|---|---|---|
| 车况概览 | 当前车辆、续航、油量/电量、点火及门锁状态；原应用实际提供的状态更新时间 | 保留，首页集中展示 |
| 基础控制 | 开锁、上锁、车窗 | 保留，放在常用区 |
| 动力控制 | 启动引擎 | 按实际使用需要保留，可放次级控制区 |
| 寻车 | 在线寻车、闪灯、鸣笛 | 保留，合并为一个“寻车”功能区 |
| 车辆状态详情 | 原应用提供的车辆状态详情 | 保留，从车况概览进入，避免重复卡片 |
| 必要设置 | 车辆切换、登录/退出、身份验证和必要车辆授权 | 保留，收进设置 |
| 车联权益 | 权益展示和服务营销入口 | 移除营销入口，控制服务到期信息按必要性保留 |
| 自定义 | 快捷入口编辑 | 可移除，最小版本使用固定布局 |

建议首页仅展示车况概览、常用控制和寻车，车辆选择及必要设置放在顶部。实际入口按当前车辆能力显示。车窗子选项尚未逐项核对，实际车辆指令尚未执行验证。
